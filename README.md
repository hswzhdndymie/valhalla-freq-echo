## Overview

Valhalla Freq Echo applies frequency shifting to each echo repeat, creating alien, psychedelic, and pitch-drifting echo effects not available with conventional pitch-shifting delays.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Valhalla Freq Echo** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Freq Shift** | Each echo repeat shifts in frequency by an adjustable amount |
| **Barberpole** | Continuously rising or falling frequency shift creates barber-pole pitch |
| **Modulation** | LFO modulates the frequency shift amount for dynamic effects |
| **Free Plugin** | Available as a free download from Valhalla DSP |
